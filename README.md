# AI TodoList for Gmail 🚀

Kill email friction. This Chrome extension auto-extracts action items buried in long, messy email threads with a single click. 

## Features
* **One-Click Extraction:** Instantly pull tasks from active email threads.
* **Zero Friction:** No manual copying or typing required.
* **Seamless Workflow:** Logs action items so nothing slips through the cracks.

## Installation
1. Install the extension from the [Chrome Web Store](#).
2. Pin the extension to your browser toolbar.
3. Open any Gmail thread and click the icon to extract your tasks instantly.
